# E-Commerce Frontend Design

This is a responsive, modern e-commerce frontend application built as an internship project.

## Technologies Used
- **React** (Bootstrapped with Vite)
- **TypeScript** for type safety
- **Tailwind CSS** for styling
- **Lucide React** for icons
- **Framer Motion** for animations

## Features
- Home Page with featured products, deals, and categories.
- Product Listing Page with product grids.
- Detailed Product View showcasing product specifications.
- Shopping Cart functionality.

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result!
